# super-twin-raid
Super Twin Raid


## About

Super Twin Raid is a work-in-progress, side-scrolling, 2D shoot-em up video game with asymmetrical local coop support for PC. It's inspired by classics like Silkworm for the Amiga 500.

Technically, Super Twin Raid is build using the [Godot Engine](https://godotengine.org/) and the final version will be based on sprites rendered from 3D models hand-built by the developer in Blender. Early prototypes will come with placeholders based on my fearsome drawing skills. Don't say you haven't been warned.
